# 面试问答与简历描述

## 一句话项目描述

设计并实现一个基于 LLM 的岗位逆向检索 Demo，将简历与目标岗位要求分离建模，生成岗位画像并集成开源 CDP 采集组件，输出带匹配理由的岗位推荐清单。

## 可写进简历的成果描述

> 基于 LLM 设计岗位逆向检索 Demo：输入简历、目标岗位方向和参考 JD，生成结构化岗位画像，对固定岗位样本进行证据化评分，并按匹配度输出带推荐理由的岗位清单。项目集成开源 Chrome CDP 采集组件，保留固定样例模式用于稳定演示。

## 面试解释重点

1. 项目为什么存在：招聘平台推荐不够精准，希望先明确目标岗位画像，再反向筛选岗位。
2. 系统怎么工作：先拆出候选人证据和目标岗位画像，再对每条岗位 JD 输出分维度评分和理由。
3. 岗位数据怎么处理：使用固定样例或实时只读采集，不发送消息、打招呼或投递。
4. 输出什么：Markdown 岗位推荐清单，包含岗位、公司、城市、薪资、匹配分和理由。
5. 如何演示：双击 `run_web.bat` 打开本地网站，选择固定样例或实时采集后运行。

## 不建议在简历中使用的表述

- 不写“独立从零开发”，因为采集层复用了开源组件。
- 不写“高匹配准确率”或“替代人工”，因为 Demo 没有完成大规模评测。
- 不把当前 CLI 流水线称为完整自主 Agent，避免面试追问时超出实现范围。
