## 验收映射

- `demo` 模式能重复生成带完整字段的岗位推荐清单：已通过。
- `live` 模式至少真实成功运行一次，或明确记录为固定样例模式：当前为“网站已支持实时采集，真实采集待浏览器登录后验证”。
- 输入可以是真实或脱敏简历、岗位方向和参考 JD：已通过。
- `.env`、简历、真实抓取数据不会进入版本控制：已有 `.gitignore`。
- README 能支持独立解释流程，不把开源采集组件写成独立开发：已按此原则编写。
- 不要求准确率、可靠性或真实业务效果：已遵守。

## Live 模式说明

实时采集只读取岗位数据，不发送消息、打招呼或投递动作。单次只搜索 1 个关键词、1 页岗位，并限制详情数量。

## 安全边界

- 只读取岗位数据，不发送消息、打招呼或投递。
- 不突破验证码或访问控制。
- 单次低频采集，用于个人学习和展示。
- API Key 不写入代码，也不进入演示输出。
